# ghostmeridian.games

The coming-soon website for Ghost Meridian, an independent games studio.

The page lives in `index.html`, including its styles and pixel-horizon animation. There is no build step. Open the file in a browser to preview it.

GitHub Pages publishes the root of `main`. `CNAME` sets the custom domain, and `.nojekyll` disables Jekyll processing.
